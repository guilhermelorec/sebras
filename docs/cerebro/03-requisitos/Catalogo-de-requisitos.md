# Catálogo de requisitos

Processo: [[ERS]] · [[Classificacao-priorizacao]] · [[Matriz-rastreabilidade]]

## Requisitos de cliente

- [[RC01]] Controlar legendas partidárias
- [[RC02]] Controlar eleitores da zona/seção
- [[RC03]] Organizar o território eleitoral
- [[RC04]] Configurar o pleito
- [[RC05]] Registrar o voto com segurança de regra
- [[RC06]] Apurar o resultado da zona
- [[RC07]] Medir abstenção da zona

## Requisitos funcionais

- [[RF01]] Manter partido
- [[RF02]] Manter eleitor
- [[RF03]] Manter município
- [[RF04]] Manter zona
- [[RF05]] Manter seção
- [[RF06]] Manter eleição
- [[RF07]] Manter cargo
- [[RF08]] Manter candidatura
- [[RF09]] Registrar voto
- [[RF10]] Consultar resultado por zona
- [[RF11]] Consultar abstenção por zona

## Requisitos não funcionais

- [[RNF01]] Interface web
- [[RNF02]] Persistência Oracle
- [[RNF03]] Servidor WildFly
- [[RNF04]] Java 21
- [[RNF05]] Integridade transacional do voto
- [[RNF06]] UTF-8
- [[RNF07]] Sem autenticação no main
- [[RNF08]] Frontend visual opcional (adiado)

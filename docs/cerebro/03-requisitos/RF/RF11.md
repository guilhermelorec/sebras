# RF11 — Consultar abstenção por zona

O sistema deve permitir consultar abstenção por zona pela interface web da mesa eleitoral.

## Rastreio

- Caso de uso: [[CU11]]
- Não funcional: [[RNF01]], [[RNF02]]

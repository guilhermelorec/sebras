# RF09 — Registrar voto

O sistema deve permitir registrar voto pela interface web da mesa eleitoral.

## Rastreio

- Cliente: [[RC05]]
- Caso de uso: [[CU09]]
- Não funcional: [[RNF01]], [[RNF02]]
- Implementação atual: `VotoServlet /votar + VotacaoService`

## Critérios de aceite

- GET lista os registros persistidos.
- POST cria ou atualiza conforme a tela.
- Erro de regra aparece para o operador, sem corromper o banco.

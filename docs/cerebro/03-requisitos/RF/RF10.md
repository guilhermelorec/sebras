# RF10 — Consultar resultado por zona

O sistema deve permitir consultar resultado por zona pela interface web da mesa eleitoral.

## Rastreio

- Cliente: [[RC06]]
- Caso de uso: [[CU10]]
- Não funcional: [[RNF01]], [[RNF02]]
- Implementação atual: `ResultadoServlet /resultado`

## Critérios de aceite

- GET lista os registros persistidos.
- POST cria ou atualiza conforme a tela.
- Erro de regra aparece para o operador, sem corromper o banco.

# SCM-001 — Schema só com as tabelas do cérebro

Modelo: [[Solicitacao-de-mudanca]]

| Campo | Valor |
|---|---|
| Data | 2026-09-11 |
| Solicitante | Equipe Sebras |
| Tipo | corretiva |
| Afeta | [[Entidades]] · [[schema-sebras]] |
| Prioridade | 5 |
| Decisão | aprovada |

## Situação atual

`resource/schema.sql` e DAOs tinham SQL fora do ER: tabela `candidato` (legado, sem RF/CU) e seed `/zonas/seed`.

## Mudança proposta

Manter só as 10 tabelas de [[Entidades]]. Remover `candidato` e o SQL de seed de zonas.

## Justificativa

O cérebro é o norte. SQL que não está no ER/RF não entra no código.

## Impacto

- Código: removidos `Candidato*`, `ZonaService`, `ZonaSeedServlet`
- Banco: `resource/schema.sql` sem `candidato`
- Telas: nenhuma (candidato e seed não tinham tela de RF)
- Testes: recriar volume Oracle para aplicar o schema novo

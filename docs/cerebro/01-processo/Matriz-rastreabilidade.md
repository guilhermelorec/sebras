# Matriz de rastreabilidade (modelo)

Fonte: `modelo_matriz_rastreabilidade.xls`.

Abas do modelo:

| Aba | Conteúdo |
|---|---|
| Requisitos Cliente | RC01…RC41 (placeholders) |
| Requisitos Funcionais | RF01…RF41 |
| Requisitos Não Funcionais | RNF01…RNF41 |
| Produtos Trabalho | PT01…PT41 |
| RC versus RC | Dependência entre requisitos de cliente |
| RF versus RF | Dependência entre funcionais |
| RF versus RC | Cada RF cobre um RC (exemplo 1:1) |
| RF versus RNF | Cada RF associado a um RNF (exemplo 1:1) |
| PT_RF | Produto de trabalho × RF |

A planilha veio **vazia / com rótulos genéricos**. A matriz viva do Sebras é [[Matriz-rastreabilidade-sebras]].

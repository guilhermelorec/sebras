# CU04 — Manter zona

Modelo: [[Detalhamento-caso-de-uso]]

| Campo | Valor |
|---|---|
| Ator | Operador |
| RF | [[RF04]] |
| Pré-condição | Município existe. |
| RN | [[RN03]] |

## Fluxo principal

1. Informar número e município.
2. Submeter.
3. Zona na lista.

## Fluxos alternativos

1. Editar.
2. Excluir se sem seção/eleitor.

## Fluxos de exceção

1. Município inexistente.

## Pós-condições

1. Zona ligada ao município.

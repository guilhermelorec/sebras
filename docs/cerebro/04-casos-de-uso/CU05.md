# CU05 — Manter seção

Modelo: [[Detalhamento-caso-de-uso]]

| Campo | Valor |
|---|---|
| Ator | Operador |
| RF | [[RF05]] |
| Pré-condição | Zona existe. |
| RN | [[RN03]] |

## Fluxo principal

1. Informar número, zona e local.
2. Submeter.
3. Seção na lista.

## Fluxos alternativos

1. Editar local.
2. Excluir se sem eleitor.

## Fluxos de exceção

1. Zona inexistente.

## Pós-condições

1. Seção pertence à zona.

# CU09 — Registrar voto

Modelo: [[Detalhamento-caso-de-uso]]

| Campo | Valor |
|---|---|
| Ator | Operador / eleitor na mesa |
| RF | [[RF09]] |
| Pré-condição | Eleição ativa, eleitor ativo, candidatura ativa, seção da zona. |
| RN | [[RN01]] |

## Fluxo principal

1. Informar eleitor, candidatura, eleição, turno, zona e seção.
2. Submeter.
3. Sistema valida RN01–RN07.
4. Grava comparecimento e voto.

## Fluxos alternativos

1. Turno 2 somente se habilitado.

## Fluxos de exceção

1. Eleição inativa.
2. Turno errado.
3. Seção de outra zona.
4. Eleitor inativo ou de outra seção.
5. Candidatura inválida para UF/turno.
6. Eleitor já votou.

## Pós-condições

1. Um comparecimento e um voto persistidos; transação commitada.

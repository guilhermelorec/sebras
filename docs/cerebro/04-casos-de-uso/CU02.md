# CU02 — Manter eleitor

Modelo: [[Detalhamento-caso-de-uso]]

| Campo | Valor |
|---|---|
| Ator | Operador |
| RF | [[RF02]] |
| Pré-condição | Zona e seção já cadastradas. |
| RN | [[RN08]] |

## Fluxo principal

1. Informar título, nome, zona, seção.
2. Submeter.
3. Eleitor aparece na lista.

## Fluxos alternativos

1. Informar CPF.
2. Editar / desativar.

## Fluxos de exceção

1. Título duplicado (RN08).
2. Zona/seção inexistentes.

## Pós-condições

1. Eleitor persistido com título único.

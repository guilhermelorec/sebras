# CU08 — Manter candidatura

Modelo: [[Detalhamento-caso-de-uso]]

| Campo | Valor |
|---|---|
| Ator | Operador |
| RF | [[RF08]] |
| Pré-condição | Eleitor, partido, eleição e cargo existem. |
| RN | [[RN05]] |

## Fluxo principal

1. Associar eleitor, partido, eleição, cargo e número.
2. Submeter.
3. Candidatura na lista.

## Fluxos alternativos

1. Desativar candidatura.

## Fluxos de exceção

1. FKs inválidas.

## Pós-condições

1. Candidatura ativa pronta para voto.

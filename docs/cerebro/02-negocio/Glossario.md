# Glossário

| Termo | Significado no Sebras |
|---|---|
| Partido | Legenda com número, sigla, nome e flag ativo. [[Partido]] [[RF01]] |
| Eleitor | Pessoa com título único, CPF opcional, zona, seção e flags ativo/votou. [[Eleitor]] [[RF02]] |
| Município | Cidade + UF. [[Municipio]] [[RF03]] |
| Zona | Unidade eleitoral numérica ligada a um município. [[Zona]] [[RF04]] |
| Seção | Local de votação dentro de uma zona. [[Secao]] [[RF05]] |
| Eleição | Pleito com ano, turnos, flag ativa e segundo turno. [[Eleicao]] [[RF06]] |
| Cargo | Posto em disputa; UF opcional; pode permitir 2º turno. [[Cargo]] [[RF07]] |
| Candidatura | Eleitor + partido + eleição + cargo + número, flag ativa. [[Candidatura]] [[RF08]] |
| Voto | Registro de escolha numa candidatura, eleição, turno, zona e seção. [[Voto]] |
| Comparecimento | Prova de que o eleitor já votou naquele pleito/turno. Impede segundo voto. [[Comparecimento]] |
| Turno | 1 ou 2. Só aceito se for o `turno_atual` da eleição. [[RN02]] |
| Resultado por zona | Agregado de votos da zona. [[RF10]] |
| Abstenção por zona | Eleitores da zona que não compareceram. [[RF11]] |
| RC / RF / RNF / RN / CU / SCM | Ver [[Como-usar]] |
